Connect to the board

The tickets live in a private GitHub repo. Paste a GitHub token once and this browser remembers it. Every change you make is saved to the repo under your name. First time? Follow the step-by-step setup guide.

  1. Make sure you've accepted the invite to the organization on GitHub.
  2. Open GitHub → New fine-grained token.
  3. Token name: 10 Paces ticket board - yourname. Expiration: 1 year.
  4. Resource owner: choose , not your own name.
  5. Repository access: Only select repositories → .
  6. Permissions: click Add permissions, choose Contents, and set it to Read and write. Don't skip this — a token with no permissions can't see the board.
  7. Click Generate token, copy it, and paste it below. GitHub only shows it once.
If the token is waiting for approval, ask Ben to approve it in the organization's settings, then try again.

How to use the board

Your day-to-day

  1. Set Owner to your name.
  2. Tick Ready to start only to see what you can pick up now.
  3. When you start a ticket, set it to In progress.
  4. When it's ready for a look, set it to Review. Ben moves it to Done, or you do if it needs no review.

Changes save straight away ("Saving…" then "Saved") and are recorded in GitHub under your name. Your filters are remembered on this device.

Good to know

  • Tickets are grouped by section, then by enemy, stage or system. Click a group to open or close it.
  • Stretch and Later tickets are hidden until you tick Include stretch & later.
  • Other people's changes appear within about 45 seconds, or click Refresh.
  • Click a ticket's title to open it: edit its details, add a note, or delete it.
  • + New task adds a ticket. New tickets get IDs like TK-001.
  • Use notes for progress, questions and links. Everyone sees them, with your name and the date.
  • On a shared computer, click Disconnect when you're done.
  • Export CSV downloads whatever the current filters show.
